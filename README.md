# 灵感 Studio · 创作工作台

面向内容工作室的中文创作工作台。支持热点采集、资料保存、小红书图文笔记，以及独立的抖音口播与拍摄脚本创作。

## 启动

需要 Node.js 22.13 或更高版本。

```sh
npm run install:ci
npm run dev
```

开发服务器地址以终端打印为准。生产构建运行 `npm run build`。

## 使用

1. 「采集热点」使用实时采集。首次进入时，两平台的结果列表均为空。
2. 在「设置 → API 密钥管理」按需填写密钥并点击「应用配置」。TikHub 用于采集；阿里云百炼用于语音识别；通义千问用于图片、笔记文案和转写纠错；火山方舟用于 Seedream 图片生成。未配置专用千问密钥时，千问服务沿用百炼密钥；火山方舟独立使用自己的密钥。本机开发服务会将配置保存到用户目录的共享文件，后续版本自动读取；远程部署仅保留当前会话输入。供应商接口由本站服务端调用。
3. 选择采集平台，输入关键词后点击「开始采集」。每个平台保留自己的采集结果。每次展示关键词搜索返回样本中按点赞量排序的最多 10 条内容，不表示整个平台的全量热门榜。
4. 小红书支持笔记正文、封面、图集、点赞量和原文链接；抖音支持标题、文案、作者、点赞、收藏、评论、播放量，以及原始语音转写和千问纠错文本。
5. 采集抖音热点后，可点「查看抖音作品」观看原视频。选定作品后点击「获取语音文案」，才会为该视频提交转写。结果可在作品详情和抖音创作页查看，失败可按篇重试。供应商未返回的指标显示为「未提供」。
6. 打开笔记图集，切换到满意的图片后点击「存入产品资料库」。保存的是当前图片的文件本身，可在产品资料库预览、下载和移除；重复保存同一笔记的同一张图片会被识别。
7. 在作品列表或详情中点击「存入素材库」，将完整笔记正文连同标题、作者、来源存为快照。在素材库「笔记内容」中查看、复制或移除；原有整条作品收藏保留在「作品收藏」标签。
8. 在「内容创作」选择「图片优化」，上传一张产品效果图，写下重绘要求并选择 1K 或 2K。输出沿用原图比例。选择「图生图」可上传 2–10 张参考图，第一张为效果图，其余为素材原图。可选画幅为 1:1、3:4、4:3、2:3、3:2、16:9 和 9:16。
9. 文案可从想法或采集笔记生成，按标题、正文和 5 个热门标签展示。标题含 1 个表情，最多 20 个字符。正文每 30–40 个字符配一个表情，不足 30 个字符的尾段可不加。生成后在「笔记预览」审核，可手动编辑、提出修改意见并选择配图。确认完成后，作品库保存整篇笔记和配图，素材库同步保留文案。
10. 图片优化和图生图均可选择 Qwen Image 2.1 Pro、Seedream 5.0 Flash 或 Seedream 5.0 Pro。千问通过任务编号查询结果，Seedream 等待本次请求直接返回图片；等待过程中不会自动重复提交。生成结果可下载并存入产品资料库，保留实际图片文件。Seedream 生成期间不要刷新页面；如果连接中断，先核对方舟用量记录，再决定是否重新生成。
11. 在抖音采集结果中点击「引用到抖音创作」，或在「内容创作 → 抖音创作」选择当前 Top 10 中的一条视频。确认原视频口播，填写创作方向和可选的修改意见，生成完整口播与逐镜拍摄方案。未转写的视频需要先转写；没有可用口播时不会用标题或简介代替。对结果有修改意见时可带上当前稿再次改写。
12. 抖音和小红书使用各自的来源、编辑器、草稿和生成接口。抖音脚本定稿后，点击「完成并存入作品库」保存完整口播和分镜。
13. 通过侧栏「智能客服」或顶部「使用说明」提问。千问根据本站操作说明解答使用问题，可继续追问。无关话题或同时要求处理无关内容的问题会被拒绝。

## 服务端配置

本机使用 `npm run dev` 时，首次启动会创建 `%LOCALAPPDATA%\LingganStudio\api-keys.json`（Windows）。在设置中保存一次后，同一系统用户运行的后续项目版本都读取这个固定路径，无需复制 `.env` 或重新输入。macOS 使用 `~/Library/Application Support/LingganStudio/api-keys.json`；Linux 使用 `${XDG_CONFIG_HOME:-~/.config}/LingganStudio/api-keys.json`。设置页显示实际路径。

文件结构为 `{"version":1,"keys":{"tikhubKey":"…","dashscopeKey":"…","qwenKey":"…","arkKey":"…"}}`。文件留在项目目录之外，不进入 Git；留空并应用会保留原有密钥，更新某项不会清空其他项。请求时从文件读取，保存后无需重启；浏览器只获取配置状态，服务端按供应商选择密钥。手动编辑请保持 JSON 格式，不支持的版本或损坏文件不会被覆盖。

本机保存接口仅在本地开发服务启用，监听非环回访问时不会为远程请求注入本机密钥。云端部署及直接运行构建产物使用下述环境变量方式，不读取电脑文件。

生产环境可通过 Sites 环境变量设置 `TIKHUB_API_KEY`、`DASHSCOPE_API_KEY`、可选的 `QWEN_API_KEY` 和 `ARK_API_KEY`，敏感值必须标记为 secret；更改环境变量后需部署使其生效。本地变量见 `.env.example`。禁止将密钥写入源文件、浏览器持久存储或版本库。

详细端点、参数、官方文档和限制见 [接口说明](docs/api.md)。采集、转写和生成使用用户自己的服务额度，TikHub、百炼的权限和余额由供应商管理。

## 当前范围

- 在「作品库」按平台、创作日期和创作者组合筛选已完成的小红书笔记和抖音脚本。每篇作品记录首次完成的时间和创作者用户名。已登录时使用账号署名，本地未登录时可填写自己的用户名。
- 作品和配图保存在当前浏览器。旧版已审核并存入素材库的创作文案会自动归入作品库，保留原保存时间；历史记录中缺少的创作者用户名显示为「未记录」。
- 图片文件和笔记正文使用当前浏览器的 IndexedDB，刷新后仍保留。作品收藏和关键词历史保留原有存储；不跨设备同步，清除网站存储会移除本地资料。
- 采集需要有效的 TikHub 密钥，可在「设置」统一管理。

## 技术

React、TypeScript、Vinext、Cloudflare Workers。第三方 API 在服务端调用，浏览器不会直接访问带密钥的供应商 API。保留 Sites 的私有访问控制。

## 验证

`node --test tests/api.test.mjs` 运行供应商模拟响应测试。启动本地开发服务器后，执行 `node --test tests/api.test.mjs tests/integration.test.mjs`，可同时验证实际 HTTP 路由的输入、跨站请求和密钥隔离；全部测试均不消费供应商额度。类型检查为 `npx tsc --noEmit`。检查记录见 [验证说明](docs/verification.md)。
