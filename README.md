# 灵感 Studio · 创作工作台

面向内容工作室的中文创作工作台。已实现热点采集、资料保存，以及小红书图片和文案创作。

## 启动

需要 Node.js 22.13 或更高版本。

```sh
npm run install:ci
npm run dev
```

开发服务器地址以终端打印为准。生产构建运行 `npm run build`。

## 使用

1. 首次打开可浏览明确标注的演示内容。演示内容不是实时热点，不会调用付费接口。
2. 在「设置」填写 TikHub API Key 和阿里云百炼 API Key。网页输入的密钥只存于当前页面内存，刷新后清除；通过本站服务端调用供应商接口。
3. 切换到实时采集，选择平台并输入关键词。每次展示关键词搜索返回样本中按点赞量排序的最多 10 条内容，不表示整个平台的全量热门榜。
4. 小红书支持笔记正文、封面、图集、点赞量和原文链接；抖音支持标题、文案、作者、点赞、收藏、评论、播放量，以及原始语音转写和千问纠错文本。
5. 阿里云转写异步完成，单条失败可以重试，其他采集内容仍保留。供应商未返回的指标展示为「未提供」。
6. 打开笔记图集，切换到满意的图片后点击「存入产品资料库」。保存的是当前图片的文件本身，可在产品资料库预览、下载和移除；重复保存同一笔记的同一张图片会被识别。
7. 在作品列表或详情中点击「存入素材库」，将完整笔记正文连同标题、作者、来源存为快照。在素材库「笔记内容」中查看、复制或移除；原有整条作品收藏保留在「作品收藏」标签。
8. 点击第二步「内容创作」。文生图直接输入提示词；图生图上传 2–10 张参考图，第 1 张为效果图、后续为产品素材原图，使用服务端固定提示词。初始显示两个上传入口，填满后逐个增加；图片会在浏览器中压缩，整次请求上限为 8 MB。
9. 文案可输入自己的想法，或从采集笔记选择原稿改写。补充真实产品信息和使用感受后，千问按姐妹分享的自然语气生成标题、正文与话题，不编造亲历或承诺效果。结果可编辑、复制并保存素材库。
10. 图片生成使用异步任务，等待过程中不会自动重复提交。生成结果可下载并存入产品资料库，保留实际图片文件。

## 服务端配置

生产环境可通过 Sites 环境变量设置 `TIKHUB_API_KEY`、`DASHSCOPE_API_KEY`，敏感值必须标记为 secret；更改环境变量后需部署使其生效。本地变量见 `.env.example`。禁止将密钥写入源文件、浏览器持久存储或版本库。

详细端点、参数、官方文档和限制见 [接口说明](docs/api.md)。采集、转写和生成使用用户自己的服务额度，TikHub、百炼的权限和余额由供应商管理。

## 当前范围

- 左侧导航包含创作中心、产品资料库、素材库、创作汇总、AI智能服务、设置。
- 产品资料库支持采集与生成图片归档；素材库支持笔记正文、创作文案与原有作品收藏。内容创作已开放，创作汇总保留后续入口。
- 图片文件和笔记正文使用当前浏览器的 IndexedDB，刷新后仍保留。作品收藏和关键词历史保留原有存储；不跨设备同步，清除网站存储会移除本地资料。
- 在未配置有效密钥时，可以使用演示和界面交互；真实供应商端到端连通性需要有效密钥验证。

## 技术

React、TypeScript、Vinext、Cloudflare Workers。第三方 API 在服务端调用，浏览器不会直接访问带密钥的供应商 API。保留 Sites 的私有访问控制。

## 验证

`node --test tests/api.test.mjs` 运行供应商模拟响应测试。启动本地开发服务器后，执行 `node --test tests/api.test.mjs tests/integration.test.mjs`，可同时验证实际 HTTP 路由的输入、跨站请求和密钥隔离；全部测试均不消费供应商额度。类型检查为 `npx tsc --noEmit`。检查记录见 [验证说明](docs/verification.md)。
